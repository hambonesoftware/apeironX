# Apeiron X — Unofficial Browser Tribute

A playable, original-code browser homage to Ambrosia Software's *Apeiron* (1995) and *Apeiron X* (2004). Built as a self-contained HTML5 game with Canvas 2D rendering, procedural 16-bit-inspired sprite artwork, painted-looking shadows, several textured field palettes, animated particles, and custom synthesized Web Audio effects. No dependencies, tracking, or third-party game assets.

## Play

**[Open the game on GitHub Pages](https://hambonesoftware.github.io/apeironX/)** — this URL works once GitHub Pages is enabled.

If the link gives a 404, open [Settings → Pages](https://github.com/hambonesoftware/apeironX/settings/pages) and set:
- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)
- Press **Save**. GitHub normally publishes the page within a few minutes.

## Controls

| Platform | Move | Fire | Pause |
| --- | --- | --- | --- |
| Desktop | Mouse, arrows, or WASD | Hold mouse button or Space | P, Escape, or Pause button |
| iPhone / iPad | Drag your finger in the game field | Auto-fire while touching | Pause button |

Audio starts after pressing **Enter the Patch** (browser autoplay policy). **Sound On/Off** in the top bar.

## Game features

- Mouse-directed blue crystal shooter limited to the lower playfield.
- A segmented Pentipede with independently moving groups, body-splitting, turn-at-obstacle behavior, escalating wave speeds, and mushroom-spawning kills.
- Dense textured grass/earth with organic cellular cracks and changing wave palettes, independently drawn multi-variant mushroom sprites, and directional shadows.
- Animated detailed creature sprite sheets generated by art.js at runtime (Pentipede with antennae, feet and facial expression; gecko; Scobster; flea; saucer).
- Near-black original-style score panel with gold italic logo and bright blue scoring.
- Gecko, flea, scorpion/lobster, and saucer-shaped hazards.
- Power-up coins: rapid fire, spread shot, temporary shield, score multiplier, and an extra life.
- Wave-clear bonuses, multiple lives, a local best score, particle impacts, and pause.
- Responsive, touch-friendly layout and all-original procedural retro sound effects.
- Dependency-free static GitHub Pages build: index.html contains gameplay and layout; art.js creates independent procedural sprite sheets and textures.

## Status and fidelity

This is **version 0.2: visual-fidelity pass**, a playable tribute rather than an exact, licensed reimplementation of Apeiron X. The 16-bit-style sprites, field, crystal, and scoreboard were independently reconstructed with reference to historical screenshots and reviewed in a live desktop browser. The runtime completed simulation smoke tests. Native iPhone testing and exact frame-by-frame visual/audio matching are still outstanding. The original game's artwork and recordings are not included.
