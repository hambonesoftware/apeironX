# Apeiron X — Unofficial Browser Tribute

A playable, original-code browser homage to Ambrosia Software's *Apeiron* (1995) and *Apeiron X* (2004). Built as a self-contained HTML5 game with Canvas 2D rendering, shaded hand-drawn characters, animated particles, and custom synthesized Web Audio effects. No dependencies, tracking, or third-party game assets.

## Play

**[Open the game on GitHub Pages](https://hambonesoftware.github.io/apeironX/)** — this URL works once GitHub Pages is enabled.

If the link gives a 404, open [Settings → Pages](https://github.com/hambonesoftware/apeironX/settings/pages) and set:
- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)
- Press **Save**. GitHub normally publishes the page within a few minutes.

## Controls

| Platform | Move | Fire | Pause |
| --- | --- | --- | --- |
| Desktop | Mouse, arrows, or WASD | Hold mouse button or Space | P, Escape, or Pause button |
| iPhone / iPad | Drag your finger in the game field | Auto-fire while touching | Pause button |

Audio starts after pressing **Enter the Patch** (browser autoplay policy). **Sound On/Off** in the top bar.

## Game features

- Mouse-directed blue crystal shooter limited to the lower playfield.
- A segmented Pentipede with independently moving groups, body-splitting, turn-at-obstacle behavior, escalating wave speeds, and mushroom-spawning kills.
- Dense, textured grass, illustrated mushrooms with cast shadows, poison and bonus mushrooms, and shading on each creature.
- Gecko, flea, scorpion/lobster, and saucer-shaped hazards.
- Power-up coins: rapid fire, spread shot, temporary shield, score multiplier, and an extra life.
- Wave-clear bonuses, multiple lives, a local best score, particle impacts, and pause.
- Responsive, touch-friendly layout and all-original procedural retro sound effects.
- Entire game implemented in one index.html file for easy hosting.

## Status and fidelity

This is **version 0.1: a playable tribute**, not an exact or verified reimplementation of Apeiron X. Gameplay proportions, pacing, enemy behavior, sprites, and sound were approximated from historical reviews and screenshots; visual browser QA has not yet been run in this environment. Next fidelity work: measure an original gameplay recording frame-by-frame, refine the sprite silhouettes and cast shadows, tune the attack patterns and difficulty, and improve the signature sound effects. The original game's sprites and recordings are not included.
